# Modül 2 | Ders 2 | Oyun Motorlarını Karşılaştırma

## Bu Uygulamada Ne Yapıyoruz

Derste Unity için söylenenleri editörde doğruluyoruz. Üç yere bakıyoruz. Bunlar Unity Hub'daki proje şablonları, Package Manager penceresindeki paketler ve Build Profiles penceresindeki platform listesidir.

Bu derste sahne üzerinde değişiklik yapılmaz. Bu yüzden klasörde sahne dosyası yoktur. Adımları açık olan herhangi bir Unity 6 projesinde uygulayabilirsiniz.

## Adım Adım

1. Unity Hub'da New Project penceresini açın. Şablon listesinde 2D (URP), 3D (URP), 3D (HDRP), Mobile ve VR şablonlarını bulun. Şablon, belirli bir proje türü için önceden hazırlanmış ayar setidir.
2. Açık projenize dönün. Window menüsünden Package Manager penceresini açın ve sol üstteki menüden Unity Registry seçin.
3. Listede Input System, Cinemachine, Addressables, Visual Scripting ve Advertisement paketlerini arayın. Her birinin açıklamasını okuyun.
4. In Project sekmesine geçin. Bu sekme projenizde yüklü paketleri gösterir.
5. File menüsünden Build Profiles penceresini açın. Windows, macOS, Linux, Android, iOS ve Web platformlarını listede bulun.
6. Web platformuna tıklayın ve sağ tarafta açılan ayarları inceleyin. Switch Platform düğmesine basmayın. Bu işlem projedeki bütün varlıkları yeniden işler ve uzun sürer.

## Ne Gördük

| Baktığımız yer | Neyi belirler |
| --- | --- |
| Proje şablonları | Görüntüleme hattı ve başlangıç ayarları |
| Package Manager | Projeye eklenen özelliklerin kapsamı |
| Build Profiles | Oyunun yayınlanacağı platformlar |

## Kendiniz Deneyin

* Package Manager'da In Project sekmesindeki paketleri sayın. Hangileri URP şablonuyla birlikte gelmiş?
* Unity Registry'de adında 2D geçen paketleri arayın. Kaç tane buldunuz?
* Build Profiles penceresinde bilgisayarınızda yüklü olmayan bir platforma tıklayın. Unity sizden ne istiyor?
